2 Dữ liệu nhân viên — tải về máy (lần đầu trên mỗi máy)

Thông tin nhân viên (lương, KPI…) không để trên trang web. Mỗi máy cần tải về một lần theo đường link dưới đây:

Đang đọc links.txt…
  1. Bấm đường link ở trên (mở tab mới) và đăng nhập bằng tài khoản đã được cấp quyền.
  2. Tải thư mục về máy. Trên Google Drive: bấm chuột phải vào thư mục (hoặc nút ⋮) → Tải xuống; Drive sẽ nén thành một file .zip.
  3. Giải nén tại máy: chuột phải file .zip → Extract All… (Giải nén tất cả) → chọn nơi lưu, ví dụ D:\PhuLong\nhanvien.
    Thư mục sau khi giải nén phải có danhsach_nhanvien.json, _config.json và các file PL001-2026_TEN.json…
  4. Mở trang Nhân sự hoặc Bảng lương → bấm 📂 Chọn thư mục nhân viên… → chọn thư mục vừa giải nén → bấm Cho phép khi trình duyệt hỏi. Trang sẽ nhớ thư mục cho các lần sau.
  5. Dùng Chrome hoặc Edge (trình duyệt khác không ghi được file). Dữ liệu chỉ nằm trên máy bạn — sửa xong (thêm nhân viên, lưu KPI…) thì báo admin để cập nhật lên thư mục chung.
⚠ Vui lòng liên hệ admin nếu bạn không có quyền access đường link này.
